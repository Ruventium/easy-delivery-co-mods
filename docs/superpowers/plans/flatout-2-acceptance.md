# FlatOut 2 Acceptance Checklist

- [ ] Steam launch succeeds three times.
- [ ] Menu and HUD remain correctly positioned at the display resolution.
- [ ] Career save loads and a new career race starts.
- [ ] Wheel steering responds left and right with no unexpected axis inversion.
- [ ] Throttle and brake respond across their full ranges.
- [ ] Gears 1, 2, 3, 4, 5, 6, and reverse respond from the verified shifter buttons.
- [ ] A short race can be completed.
- [ ] A destruction event can be started and completed.
- [ ] Pause, restart, exit, and career save/load work.
- [ ] Keyboard fallback remains usable.
- [ ] No missing textures, broken HUD, crash, or severe frame pacing regression is observed.
