# KOTAMON Pile Unlock

BepInEx 6 IL2CPP plugin for KOTAMON.

## Features

- Allows opening another junk pile before the current pile is fully cleaned.
- Preserves the contents of previously opened piles.
- Suppresses the misleading "all junk cleaned" completion notification.
- Does not change junk pile contents, collectible spawn rules, cards, boxes, tapes, cases, or money.
- Does not auto-open piles.

## Installation

1. Install a BepInEx 6 IL2CPP x64 build compatible with Unity `6000.4.1f1`.
2. Copy `KotamonPileUnlock.dll` to `KOTAMON/BepInEx/plugins/`.
3. Start the game through Steam.

## Removal

Delete `KotamonPileUnlock.dll` from `BepInEx/plugins/`.

Back up saves before using any gameplay-changing mod. The plugin does not edit save files directly.
